# Блок «Полезные сервисы» для преподавателя

Что есть у преподавателя в сервисе и что из этого вынести ключевыми блоками на ПК-главную (`useful-section` в `src/components/DesktopHome.vue`). Источники: `ROLES_SPEC.md` §3.5 и эндпоинты `fefumap-backend-sql`.

Раскладка блока не меняется: **две панели + компактные плитки**. Для студента это расписание пар, шаттлы и плитки. Для преподавателя меняется содержимое панелей и плиток.

---

## 1. Кто такой преподаватель в системе

Это не роль из админки, а **контекст**: у пользователя есть записи `ed_teachers` (из штатного расписания или привязанные вручную). Определяется через `GET /education/me/roles` (`is_teacher`, `available_modes`, `active_mode`).

В режиме `teacher` все списки (пары, группы, дисциплины, студенты) жёстко ограничены **его** парами. Режим переключается через `PUT /education/me/roles`. Если преподаватель ещё и студент, режим выбирает, какой набор показывать.

---

## 2. Что у преподавателя есть

| Область | Что может |
|---|---|
| **Расписание** | свои пары на день и по дням; все пары — только просмотр |
| **Начать пару** | отсканировать QR аудитории; пара получает статус `not_started` / `started` / `started_late` / `disrupted` |
| **Посещаемость** | ставить и править отметки (`done`, `late`, `sick`, `good_reason`, `not_planned`) вручную или по QR студента; правка доступна только в окне редактирования |
| **Причина опоздания / срыва** | указать причину по своей паре (пробки, технический сбой, прошлая пара затянулась, расстояние между кабинетами, другое) |
| **Проблемы в аудитории** | сообщить о проблеме по паре с файлами; смотреть свои обращения |
| **Студенты** | список «группа × дисциплина», последнее посещение, статистика, флаг «в зоне риска» (посещаемость ≤ 50 %) |
| **Подгруппы** | распределять студентов по своим дисциплинам; видеть нераспределённых |
| **Старосты** | назначать и снимать по своим дисциплинам |
| **Обратная связь по занятиям** | динамика и распределение оценок студентов (анонимно) по своим дисциплинам |
| **Кабинет преподавателя** (только ПК) | главная, «Мои занятия», расписание, журналы, журнал дисциплины, журнал пары |
| **Общие сервисы** | карта, бронирование аудиторий и оборудования, аренда переносного оборудования, мои заявки, шаттлы, мероприятия |

---

## 3. Ключевые блоки для главной

Главные задачи преподавателя в течение дня: **начать пару**, **отметить студентов**, **не пропустить то, что требует действия**, найти аудиторию.

### Плашка пары (над «Полезными сервисами»)

Решение по обратной связи от ответственного за раздел (25.11.2026). Плашка обязательна на ПК.

| Когда | Что показывает | Действия |
|---|---|---|
| За 15 минут до начала пары | место и время («Корпус A, A914 · 13:00–14:30»), дисциплина, группа и вид занятия | «Начать пару», «Отметить студентов» |
| Во время пары | то же + метка «Идёт» — без отдельного предупреждения об опоздании, даже если пара не начата | только «Отметить студентов» |
| В остальное время | плашки нет | — |

Обратного отсчёта («Пара начнётся через N минут») и цветной полосы слева нет (правка 26.11.2026).

В прототипе расписание преподавателя демо, поэтому часы тоже демо: по умолчанию 12:48 (за 12 минут до третьей пары). `?lessonAt=HH:MM` задаёт другое время, `?lessonAt=real` — реальное время кампуса.

### Панель 1 — «Занятия сегодня»

Аналог студенческого «Расписания».

| Элемент | Содержимое |
|---|---|
| Заголовок | «Занятия сегодня», без строки с датой (раньше «Мои пары») |
| Строка пары | время, дисциплина, группа, аудитория (корпус и номер) |
| Статус | чип: `Не начата` / `Идёт` / `Начата с опозданием` / `Сорвана` |
| Действие | **«Начать пару»** (открывает QR-сканер); для идущей пары — «Отметки» (журнал пары) |
| Проблема в аудитории | действие внутри строки пары, не отдельная плитка |
| Стрелка панели | Кабинет преподавателя → расписание |

Данные: `GET /education/pairs`, `/pairs/days`.
Пусто: «Сегодня пар нет», дальше показывается следующий день с парами.

### Панель 2 — «Требует внимания»

Замена студенческих шаттлов: короткие задачи, собранные в группы по типу. Группа показывается, только если в ней есть строки; если задач нет — «Всё в порядке». Разделителей нет ни между строками, ни между группами — группы отделены отступом (правка 27.11.2026).

| Группа | Строки | Когда появляется | Источник |
|---|---|---|---|
| Укажите причину опоздания | по строке на пару: дисциплина, время | пара `started_late` / `disrupted`, `can_set = true` | `get_pair_delay_reason` |
| Правка отметок | по строке на пару: дисциплина, «время · до HH:MM · не отмечено: N» | пара закончилась, окно правки ещё открыто | `can_edit` пары |
| Студенты | «Студенты в зоне риска» (посещаемость ≤ 50 %), «Студенты без подгруппы» — без счётчиков | есть такие студенты по дисциплинам преподавателя | `GET /education/students`, `get_unassigned_students` |
| Оценки занятий | «N новых оценок», под ней самый слабый критерий | студенты оценили пары | `get_feedback_dynamics` |
| Заявки на модерации | по строке на заявку преподавателя: название, дата | заявка в статусе «на рассмотрении» | `/reservations` |

## 4. Условия показа

| Виджет | Условие |
|---|---|
| Панели и плитки кабинета | `is_teacher = true` или право `EDUCATION_ATTENDANCE.read` у активной роли |
| «Занятия сегодня» с кнопкой «Начать пару» | активный режим `teacher` (в других режимах пары видны без кнопки) |
| Плитки «Журналы» и «Кабинет» | только ПК (на мобильном кабинет недоступен) |
| Бронирование, Аренда, Мои заявки, Карта, Шаттлы | любой вошедший пользователь |

## 5. Что нужно от бэкенда

Сводного эндпоинта для главной нет. Панель 2 сейчас собирается из 5–6 запросов в разных модулях. Лучше добавить `GET /me/home/summary`, который по активному режиму вернёт только числа и ссылки на фильтры. Пока его нет, собирать счётчики параллельно и показывать строки по мере загрузки (скелетоны).
