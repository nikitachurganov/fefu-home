# ТЗ: доработка блока «События» на главной (мобильная версия)

Стек: Vue 3 (`<script setup>`), Ant Design Vue 4, Vitest. Тесты: `npm test`, сборка: `npm run build`.
Комментарии в коде и тексты интерфейса — на русском, в стиле существующих файлов.

## 0. Контекст

Блок событий — это слайдер карточек под строкой погоды на главной.

- Компонент: `src/components/MobileSessionSlider.vue`.
- Подключён в `src/App.vue` (около строки 249) так:
  `<MobileSessionSlider v-if="isAuthenticated && activeHighlights.length" ... />`.
- Данные: `activeHighlights` — заявки со `status === 'active'` (`src/data/requests.js`, поле `source`: `events`, `equipment`, `tmc`, `workplace`).
- Родственная карточка с той же логикой: `src/components/RequestHighlightCard.vue`. Она используется в списках («Заявки», виджет «Сейчас у вас»).
- Нижняя шторка: `src/components/BottomSheet.vue`. На мобильном это `a-drawer`, на ПК (≥1024px) центрированный `a-modal`. Содержимое передаётся через слот. Образец использования — `src/components/ClassStartSheet.vue`.

Нужно сделать три вещи: пустое состояние, выравнивание карточек и шторку «Подробнее». Всё это только для мобильной версии. Десктопную главную (`DesktopHome.vue`) не трогаем.

## 1. Пустое состояние блока событий

### Что сейчас
Если активных событий нет, блока на главной просто нет: слайдер скрыт через `v-if`.

### Что нужно
Для авторизованного пользователя без активных событий показывать карточку-заглушку на том же месте, где обычно стоит слайдер.

Для гостей (`!isAuthenticated`) поведение не меняем: блока по-прежнему нет.

### Реализация
- Новый компонент `src/components/EventsEmptyCard.vue`.
- В `App.vue` условие меняется так:
  - `isAuthenticated && activeHighlights.length` → `MobileSessionSlider`.
  - `isAuthenticated && !activeHighlights.length` → `EventsEmptyCard`.
- Отступ снизу такой же, как у слайдера (`margin-bottom: 12px`). Карточка не должна выходить за поля страницы.

### Макет (горизонтальная карточка)
- Фон белый, скругление 12px (как у остальных карточек главной), без обводки и тени.
- Слева колонка с тремя строками:
  1. Заголовок «Сегодня нет событий»: жирный (700), 17–18px, цвет `rgba(0,0,0,.88)`.
  2. Подзаголовок «Новые события появятся здесь»: 15px, серый `rgba(0,0,0,.45–.65)`.
  3. Ссылка «Подробнее»: 15px, цвет акцента `#2867ab`, без подчёркивания.
- Справа иллюстрация «пустой лоток с облачком сообщения» (серо-голубая, лёгкая). Размер около 112×88px, прижата вправо и по центру по вертикали, под текст не заезжает.
- Иллюстрацию взять из Figma-макета пустого состояния. Если её нет в `src/assets/figma/`, выгрузить из макета в SVG. Если выгрузить не получается, поставить временный простой SVG-плейсхолдер и явно написать об этом в отчёте.
- Минимальная высота около 120px. Заголовок и подзаголовок переносятся на две строки без обрезания на экранах шириной от 320px.
- Тексты вынести в константы вверху компонента. Они должны быть общими для всех типов событий и не привязываться к занятиям, броням или мероприятиям.

### Поведение
- Вся карточка не кликабельна. Интерактивна только ссылка «Подробнее».
- «Подробнее» — это `<button type="button" class="link">`, он эмитит `open-info`. `App.vue` открывает шторку из раздела 3.
- Доступность: у карточки `role="region"` и `aria-label="События"`. У кнопки видимый `:focus-visible` (`outline: 2px solid #2867ab`).

## 2. Доработка карточки события (`is-soon` и `is-in-progress`)

### Проблема 1: два состояния выглядят по-разному
- `is-soon` («Пара скоро начнётся») — сплошной `#121212`, почти чёрный.
- `is-in-progress` («Пара идёт») — `rgba(18,18,18,.85)` с `backdrop-filter: blur(10px)`.

Над светло-серым фоном страницы (`#f2f2f2`) полупрозрачный вариант даёт серый `~#3a3a3a`. Поэтому карточки в слайдере разного цвета.

### Что сделать
- В `MobileSessionSlider.vue` и `RequestHighlightCard.vue` задать обоим состояниям одинаковый сплошной тёмный фон `#121212`.
- Убрать `rgba(...)`, `backdrop-filter` и `-webkit-backdrop-filter` у `.is-in-progress`.
- Если в проекте есть подходящий токен тёмной поверхности (смотри `docs/design-tokens.md` и `src/styles.css`), использовать его вместо хардкода.
- Состояния отличаются только содержимым: цвет точки статуса, текст статуса и полоса прогресса (она только у «идёт»). Тип карточки на цвет фона не влияет.
- Проверить, что у всех трёх `.session-card` (`is-soon`, `is-in-progress`, `is-standard`) тот же сплошной цвет. Тогда все карточки слайдера выглядят одинаково.

### Проблема 2: водяной знак (иконка шапочки) почти не виден
Причина — двойное затухание. В `src/assets/figma/edu-watermark.svg` у группы уже стоит `opacity="0.2"`, а в CSS ещё `.session-watermark { opacity: 0.22 }`. Итоговая непрозрачность около 4%.

### Что сделать
- Убрать лишнее затухание: в CSS (`.session-watermark` и `.card-watermark`) поставить `opacity: 1`.
- Итоговую яркость регулировать только атрибутом `opacity` у группы в SVG. Подобрать так, чтобы шапочка уверенно читалась на `#121212`, но не спорила с текстом. Ориентир — эффективная непрозрачность 0.25–0.35.
- Положение (`top: -25px; right: -9px; 120×120`) оставить. Если после правки знак перекрывает заголовок, сместить на несколько пикселей и обрезать по карточке (`overflow: clip` уже есть).
- Проверить в обоих состояниях, в том числе на экране 320px.

Логику таймеров, статусов, прогресс-полосы и свайпа не менять.

## 3. Шторка «Подробнее»

### Открытие
Из `EventsEmptyCard` (кнопка «Подробнее») открывается нижняя шторка через существующий `BottomSheet`, содержимое — через слот.

- Новый компонент `src/components/EventsInfoSheet.vue`.
- Пропсы: `open: Boolean`, `zIndex: Number`. Событие: `close`.
- Образец структуры, стилей заголовка и отступов — `ClassStartSheet.vue`.
- Закрытие: кнопка «Закрыть» внизу, свайп за ручку, маска (всё это уже есть в `BottomSheet`).
- В `App.vue` добавить `eventsInfoOpen = ref(false)` и привязать к `EventsEmptyCard` и `EventsInfoSheet` так же, как сделано для `ClassStartSheet` или `StudentCodeSheet`.

### Содержимое
- Заголовок: «Какие события здесь появятся» (19px, 700, как `.sheet-title` в `ClassStartSheet`).
- Подпись: «В этом блоке мы показываем ближайшие и текущие события из ваших сервисов» (13px, серая).
- Список из четырёх карточек (серый фон `#f3f3f3`, скругление 12px, внутренний отступ 12–16px, расстояние между карточками 8px). В карточке слева иконка 40×40, справа название (15px, 600) и описание (13px, серое):

| Название | Описание |
|---|---|
| Занятия | Пары по вашему расписанию |
| Мероприятия | События, на которые вы записаны |
| Аренда ТМЦ (инвентаря) | Выдача и возврат инвентаря |
| Бронирование оборудования и пространств | Аудитории, коворкинги и техника |

- Иконки взять из тех же ассетов, что у сервисов на главной (Расписание, Мероприятия, Аренда, Бронирование). Новые не рисовать. Найти их через `src/data/assets.js` или импорты иконок в `App.vue`.
- Карточки информационные: не кликабельные, без `cursor: pointer`, без ссылок.
- Внизу кнопка «Закрыть» в стиле `.btn-cancel` из `ClassStartSheet`.
- Список данных вынести в массив константы внутри компонента, чтобы категории легко добавлять.

### ПК
`BottomSheet` на ширине ≥1024px сам превращается в модал. Отдельной вёрстки не нужно.

## 4. Тесты и проверка

- Добавить тесты Vitest по образцу существующих (`*.test.js` рядом с компонентом).
  - `EventsEmptyCard`: рендерит заголовок и подзаголовок, кнопка «Подробнее» эмитит `open-info`.
  - `EventsInfoSheet`: рендерит все четыре категории; закрытие эмитит `close`.
  - Для `MobileSessionSlider` и `RequestHighlightCard` проверить, что состояния `is-soon` и `is-in-progress` не используют полупрозрачный фон (например, по CSS-правилам или классам).
- Прогнать `npm test` и `npm run build`. Всё должно проходить, существующие тесты не ломать.
- Визуально проверить на ширинах 320, 375 и 402px: пустое состояние, слайдер с двумя карточками (`soon` и `in_progress`), шторка. Убедиться, что фон карточек слайдера одинаковый, а шапочка видна.

## 5. Границы работы

- Не менять модель данных (`requests.js`, `requestModel.js`), таймеры и логику статусов.
- Не менять `DesktopHome.vue` и виджеты в `src/components/widgets/`.
- Не добавлять новые зависимости.
- Не трогать несвязанные файлы, в том числе те, что сейчас в рабочем дереве изменены (`RequestsPage.vue`, `styles.css` и др.), кроме точечных правок по этому ТЗ.
- Если нужна иллюстрация или иконка, которых нет в репозитории, не выдумывать их: использовать плейсхолдер и отметить это в отчёте.

## 6. Критерии приёмки

1. Авторизованный пользователь без активных событий видит белую карточку «Сегодня нет событий / Новые события появятся здесь / Подробнее» с иллюстрацией справа.
2. Гость блока по-прежнему не видит.
3. «Подробнее» открывает нижнюю шторку с четырьмя карточками: Занятия, Мероприятия, Аренда ТМЦ (инвентаря), Бронирование оборудования и пространств. Шторка закрывается кнопкой, свайпом и по маске.
4. Карточки «Пара скоро начнётся» и «Пара идёт» одного и того же цвета `#121212`.
5. Иконка шапочки на карточках хорошо различима.
6. `npm test` и `npm run build` проходят без ошибок.
